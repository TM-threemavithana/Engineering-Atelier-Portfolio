## Conceptual Overview

StreamForge is an illustrative distributed log architecture exploring consensus replication, bounded event buffering, and durable sequential persistence using Java 21 virtual threads.

## Architecture & Design Boundaries

The architecture separates network ingestion via gRPC services from the consensus replication loop, maintaining explicit bounded memory queues to prevent unconstrained heap expansion during network partitions.
